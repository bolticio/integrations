# Dropbox

Dropbox is used to store, sync, and share files securely across devices and with others.

## Dropbox Account

- Select the Dropbox you want to connect.
- If you don't have an existing account, please add one using the **Add New Account** option before proceeding.

## Available Resources

Here are some of the available resources you can use with the **Dropbox** node:

### Resources

- **File**: A file in Dropbox is any document, image, video, etc., that you can upload, preview and share via link with others.
- **Folder**: A folder in Dropbox is used to organize files and can be shared with others, allowing multiple users to access, upload, edit, and manage files collaboratively in one place.

## Basic Operations

Here are some of the basic operations you can perform with the Dropbox node:

### File

- **Create Text File**: Creates a new Text File.
- **Share File**: Share an Existing File.
- **Copy File**: Copy an Existing File and Add to New Location.
- **Delete File**: Deletes an Existing File in Dropbox.
- **Move File**: Moves File From One Location to Another.

### Folder

- **Create Folder**: Creates a new Folder in Dropbox.
- **Share Folder**: Share an Existing Folder.
- **Add Member To Folder**: Add Member To an Existing Folder.
- **Find Folder or File**: Find an Existing Folder or File.
- **Delete Folder**: Deletes an Existing Folder in Dropbox.

## Conclusion

Dropbox is a cloud-based platform that lets you back up, access, and collaborate on files anytime from anywhere.
