# Microsoft Outlook

The Microsoft Outlook node enables your applications to interact with the Microsoft Outlook , allowing you to automate and manage emails, calendar events, contacts, and more. This guide will help you authenticate and perform various operations within your Microsoft Outlook account.

## Microsoft Outlook Account

- Select the Microsoft Outlook account you want to connect.
- If you don't have an existing account, please add one using the "Add New Account" option before proceeding.

## Available Resources

Here are some of the available resources you can use with the **Microsoft Outlook** node:

### Resources

- **Mail**: Allows users to send, receive, and manage emails.
- **Contact**: Lets users store and organize contact information.
- **Calendar**: Helps create and manage events and meetings.
- **Custom**: Send requests to any OneDrive endpoint using a provided URL and HTTP method.

## Basic Operations

Here are some of the basic operations you can perform with the Microsoft Outlook node:

### Mail

- **Send Email**:Send an email to one or more recipients.
- **Create Draft Mail**:Create an email draft without sending it.
- **Send Draft Mail**:Send a previously saved draft email.
- **Reply or Forward**:Reply to an existing email message.
- **Find an Email**:Retrieve details of a specific email.

### Calendar

- **Create an Event**: Create a new calendar event.
- **Update an Event**: Modify event details such as time, location, or attendees.
- **Get Event Details**: Retrieve information about a specific event.
- **Add Attendees**: Add participants to an existing calendar event.
- **Delete an Event**: Remove a calendar event permanently.

### Contacts

- **Create a Contact**: Add a new contact to your Microsoft Outlook address book.
- **Update a Contact**: Edit existing contact details.
- **Get Contact Details**: Search for a contact by name, email, or other fields.

## Conclusion

The Microsoft Outlook node provides a robust set of tools for managing your email, calendar, and contacts efficiently. By setting up authentication and using the available operations, you can automate communication, scheduling, and contact management workflows directly within your applications.
