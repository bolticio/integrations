# Microsoft Outlook

## Overview

Microsoft Outlook is an email and productivity platform that helps users manage emails, calendars, and contacts in one place.
## Authentication Ways

- Microsoft OAuth (OAuth 2.0)

## Microsoft OAuth (OAuth 2.0)
Users only need to sign in and grant permission to access their Outlook.

**Steps:**
1. **Click Connect Microsoft Outlook Account**

2. **Sign in with your Microsoft Email and Password**

3. **Review and allow the requested permissions**

    - Mail.ReadWrite

    - Calendars.ReadWrite

    - Contacts.ReadWrite

4. **After successful authorization, your Microsoft Outlook account will be connected**
