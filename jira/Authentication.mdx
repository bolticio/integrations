# Jira Cloud

## Overview
Jira Cloud provides a powerful platform for issue tracking, project management, and workflow automation. Developers can integrate Jira Cloud with Boltic to manage tickets, monitor project progress, and automate workflows securely.  
Access to Jira Cloud's API is authenticated using **Basic Authentication (Email & Personal Access Token)** to ensure secure and authorized communication.

## Authentication Ways

- Basic Authentication (Email & Personal Access Token)

## Basic Authentication (Email & Personal Access Token)

To authenticate with Jira Cloud, you need your Jira domain URL, the email address associated with your Atlassian account, and a personal access token generated from your Jira account.

**Steps:**

1. **Sign in to Your Atlassian Account**  
   - Go to <a href="https://id.atlassian.com/manage-profile/security/api-tokens" target="_blank" rel="noopener"><span>Atlassian Account Settings</span></a> and log in to your Jira account.

2. **Generate a Personal Access Token**  
   - Under the **Security** section, select **Create and manage API tokens**.  
   - Click **Create API token**, provide a label (e.g., "Boltic Integration"), and click **Create**.  
   - Copy and securely store your newly generated token.

3. **Gather Required Credentials**  
   - **Domain URL:** Your Jira site domain (e.g., `https://yourcompany.atlassian.net`)  
   - **Email Address:** The email linked to your Atlassian account  
   - **Personal Access Token:** The API token created in step 2

4. **Set Up the Jira Integration in Boltic**  
   - Log in to your Boltic dashboard.  
   - Navigate to **Sources → + Add New Source → Search for "Jira"**.  
   - Fill in the required details:  
     - **Name:** Enter a name for your Jira integration.  
     - **Domain:** Paste your Jira domain URL.  
     - **Email:** Enter your Atlassian account email.  
     - **Personal Access Token:** Paste your generated token.  
   - Click **Test Connection** to verify authentication, then select **Set up source** once successful.
