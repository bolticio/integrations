#Jira is a powerful project management and issue tracking platform that helps teams plan, track, and deliver software efficiently.  
With the Jira node, you can automate operations such as creating issues, managing projects, and updating tickets directly from Boltic.

## Getting Started

Before using the Jira node, you'll need to complete a few setup steps.

### Prerequisites

- **Atlassian Account**: Sign up for an account at <a href="https://www.atlassian.com/" target="_blank">atlassian.com</a> if you don't already have one.  
- **Jira Domain URL**: Your Jira Cloud instance domain (e.g., `https://yourcompany.atlassian.net`).  
- **Jira API Token**: Generate a personal access token from your Atlassian account by following the instructions in the <a href="https://support.atlassian.com/atlassian-account/docs/manage-api-tokens-for-your-atlassian-account/" target="_blank">Jira API Token documentation</a>.

### Supported Authentication Methods

The Jira node supports the following authentication method:

- **Personal Access Token (Email & API Token)**: Authenticate securely with your Jira account credentials.

## Basic Operations

Here are some of the core operations you can perform with the Jira node:

### Projects
- **List Projects**: Retrieve a list of available projects in your Jira instance.

### Issues
- **Create Issue**: Create a new issue in a selected project.  
- **Retrieve Issue**: Get detailed information about a specific issue by key or ID.  
- **Retrieve All Issues**: Fetch a list of all issues in your Jira project with optional filtering.  
- **Delete Issue**: Permanently delete a specific issue from Jira.

## Conclusion

The Jira node makes it simple to integrate issue management and project tracking into your workflows. You can use it to automate ticket creation, synchronize data between systems, or monitor project progress—all securely and efficiently.
