# Google Tasks Integration

Google Tasks is a lightweight to do list application from Google that allows users to create, manage, and track tasks across devices. The Google Tasks node in Boltic lets you connect your account and automate task list and task operations.

## Google Tasks Account

- Select the Google Tasks account you want to connect.
- If you do not have an existing account, add one using the **Add New Account** option before proceeding.

## Available Resources

Here are the available resources you can use with the **Google Tasks** node:

### Resources
- **Task Lists**: Organize tasks into lists and manage task list details.
- **Tasks**: Create and manage tasks within lists, including status, updates, and moves.

## Basic Operations

Here are the basic operations you can perform with the Google Tasks node:

### Task Lists
- **Get Task Lists**: Get a list of all task lists.
- **Get Task List Details**: Retrieve details for a specific task list.
- **Create Task List**: Create a new task list.
- **Rename Task List**: Rename a task list.
- **Delete Task List**: Delete a specific task list.

### Tasks
- **Get Tasks**: Get a list of tasks in a task list.
- **Get Task Details**: Retrieve details for a specific task.
- **Create Task**: Create a new task.
- **Update Task**: Update a task.
- **Delete Task**: Delete a specific task.
- **Move Task to Task List**: Move a task to another task list.

## Conclusion

Google Tasks helps you automate personal and team task workflows inside Boltic. Use the Google Tasks node to manage task lists and tasks in your workflows.
