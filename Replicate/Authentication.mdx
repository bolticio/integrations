# Replicate Authentication

## Overview

The Replicate integration lets Boltic workflows run machine learning models, manage predictions, trainings, deployments, and more.
Replicate APIs in Boltic use API Key authentication for connecting your Replicate account.

## Authentication

Authenticate Replicate using an API Key.

Steps:

1. Sign in to Replicate -
Log in to your Replicate account at replicate.com.

2. Generate an API Key -
Go to your Replicate account settings and create an API token. Refer to Replicate's authentication documentation for detailed instructions.

3. Open Boltic -
Go to the Replicate source configuration page in Boltic.

4. Authentication Type -
The authentication type is `API Key`.

5. Enter API Key -
Paste your API key into the **API Key** field.

6. Save and Continue -
Save the configuration and proceed with the setup in Boltic.

If you need further assistance, please contact Boltic support support@boltic.io.
