# Fynd Intelligence Reports

This integration allows you to generate analytics reports using the Fynd Platform.

## Authentication
This node uses **Fynd Platform integration**.

## How to use
Follow these steps to configure the node and generate reports:

1.  **Fynd Commerce Account**: Select your configured Fynd Commerce Account or add one.
2.  **Resource**: Select **Analytics Reports**.
3.  **Operation**: Select **Generate Report**.
4.  **Product Line**: Choose the appropriate product line (e.g., Fynd Commerce, Fynd StoreOS, Fynd Konnect, Fynd CommerceB2B).
5.  **Notification Email ID**: Enter the email ID where the report notification should be sent.
6.  **Report**: Select the specific report you want to generate.
7.  **Report Parameters**: Once a report is selected, relevant questions (parameters) will appear, such as **Time Gap** or **Sales Channel**. Fill these in as required.
