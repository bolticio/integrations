# Fynd Intelligence

Generate analytics reports and share dashboard snapshots.

---

## Authentication
This node uses Fynd Platform integration.


## 1. Setup

### Fynd Commerce Account
Select your configured account.

---

### Resource
Choose one:

- **Analytics Reports**
- **Dashboard Snapshots**

![Select Resource](https://cdn.pixelbin.io/v2/patient-mouse-6b0745/t.resize(w:500)/public/dumps/fyndintelligence-bolticnode-resouse-node.png)

---

### Operation

- **Analytics Reports** → Generate Report  
- **Dashboard Snapshots** → Share Snapshot via Email  

---

## 2. Configure

### Generate Report — Properties

- **Product Line**  
  Select the applicable product line (Fynd Commerce, StoreOS, Konnect, CommerceB2B).

- **Notification Email ID**  
  Email address where the generated report notification will be sent.

- **Report**  
  Select a report template. Available options depend on the selected product line.

- **Dynamic Parameters**  
  Additional filters appear based on the selected report (e.g., Time Gap, Location, Sales Channel).

![Dynamic Report Parameters](https://cdn.pixelbin.io/v2/patient-mouse-6b0745/t.resize(w:500)/public/dumps/fyndintelligence-bolticnode-reports-dynamic-properties.png)

---

### Share Snapshot via Email — Properties

- **Product Line**  
  Select the applicable product line (currently Fynd Commerce).

- **Dashboards**  
  Select the dashboard to capture from the dropdown list.

- **Notification Email(s)**  
  Enter one or more comma-separated email addresses to receive the snapshot.

![Snapshot Configuration](https://cdn.pixelbin.io/v2/patient-mouse-6b0745/t.resize(w:500)/public/dumps/fyndintelligence-bolticnode-snapshot-example-1.png)
