## Zoho Analytics

### Overview
The ZohoAnalytics node allows you to connect your application with Zoho Analytics to automate tasks such as data analysis, report generation, dashboard creation, and workspace management. It helps streamline your business intelligence and data analytics workflows by enabling seamless integration with your analytics data.

### Authentication Ways
- OAuth 2.0 <a href="https://www.zoho.com/analytics/api/v2/authentication.html" target="_blank">Zoho Documentation</a>

### OAuth 2.0
To use the ZohoAnalytics node, you need to authenticate using OAuth 2.0. Follow the steps below to set up your OAuth credentials and authorize access to your Zoho Analytics data.

**Steps:**
1. **Connect via Boltic**
   - In Boltic's integration configuration, select ZohoAnalytics and enter a Name for your connection.

2. **Authorize Access**
   - Click Connect or Authorize.
   - You will be redirected to the Zoho Accounts login and consent screen.
   - Sign in with your Zoho credentials and grant the requested scopes (e.g. `ZohoAnalytics.data.read`, `ZohoAnalytics.data.create`, `ZohoAnalytics.data.update`, `ZohoAnalytics.metadata.read`, `ZohoAnalytics.fullaccess.all`, etc.).
   - Once the Connect button indicator turns green, return to Boltic and click Save — your OAuth tokens are now securely stored.

3. **Token Handling**
   - After successful authorization, Boltic securely stores both the access token and refresh token.
   - Access tokens are valid for 1 hour; when they expire, Boltic will automatically use the refresh token to obtain a new access token behind the scenes.

For detailed API usage (endpoints, request/response formats, supported modules and operations), see the <a href="https://www.zoho.com/analytics/api/v2/introduction.html" target="_blank">Zoho Analytics API reference</a>
