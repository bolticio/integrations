## Zoho FSM Authentication

### Overview

Connect Boltic to Zoho FSM to automate workflows like adding requests and updating requests.

### Authentication Ways

- OAuth 2.0 (`Zoho Accounts`)

### OAuth 2.0

To use the Zoho FSM node, authenticate using OAuth 2.0.

Steps:

1. Connect via Boltic

   - In Boltic’s integration configuration, select Zoho FSM and enter a Name for your connection.

2. Authorize Access

   - Click Connect or Authorize.
   - You will be redirected to Zoho Accounts to grant access.
   - Approve the requested scopes listed below.
   - Once connected, return to Boltic and click Save — your OAuth tokens are now securely stored.

3. Token Handling
   - Access tokens expire periodically. Boltic automatically refreshes tokens using the refresh token.

### Scopes Used

- ZohoFSM.modules.Requests.READ
- ZohoFSM.modules.Requests.CREATE
- ZohoFSM.modules.Requests.UPDATE
- ZohoFSM.modules.Contacts.READ
- ZohoFSM.modules.Companies.READ
- ZohoFSM.modules.Territories.READ
- ZohoFSM.modules.Assets.READ
