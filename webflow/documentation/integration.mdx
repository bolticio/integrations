# Webflow

Webflow is a website experience platform for designing, building, and managing websites, forms, CMS content, ecommerce products, assets, pages, and comments. The Webflow node in Boltic lets you connect your Webflow account and automate common site, CMS, and ecommerce workflows.

## Webflow Account

- Select the Webflow account you want to connect.
- If you don't have an existing account, add one using the **Add New Account** option before proceeding.
- Your Webflow credentials are encrypted and can be removed at any time.

## Available Resources

Here are the available resources you can use with the **Webflow** node:

### Resources
- **Sites**: Manage Webflow sites — list sites, retrieve site details, list custom domains, and publish sites.
- **Collections**: Work with CMS collections — list collections, retrieve collection details, and delete a collection.
- **Items**: Manage CMS collection items — list, retrieve, create, update, publish, and delete items.
- **Products**: Manage ecommerce products — list, retrieve, create, update products, and update product SKUs.
- **Inventory**: Manage SKU inventory — get and update inventory levels for SKU items.
- **Assets**: Manage hosted assets — list assets, get metadata, delete assets, and manage asset folders.
- **Forms**: Work with forms — list forms, retrieve schemas, list submissions, retrieve, update, and delete submissions.
- **Pages**: Work with pages — list pages and retrieve page metadata.
- **Comments**: Work with page comments — list comment threads, retrieve a thread, and list thread replies.
- **Custom API**: Execute custom authenticated Webflow API calls with full flexibility.


## Basic Operations

Here are the basic operations you can perform with the Webflow node:

### Sites
- **List Sites**: List all accessible Webflow sites.
- **Get Site**: Retrieve details for a specific site.
- **Get Custom Domains**: List custom domains configured for a site.
- **Publish Site**: Publish a site to selected custom domains and optionally to the Webflow subdomain.

### Collections
- **List Collections**: List collections for a selected site.
- **Get Collection**: Retrieve details for a selected collection.
- **Delete Collection**: Delete a selected collection.

### Items
- **List Items**: List items for a selected collection.
- **Get Item**: Retrieve a selected collection item.
- **Create Item**: Create a new item in a collection.
- **Update Item**: Update an existing collection item.
- **Publish Item**: Publish one or more collection items.
- **Delete Item**: Delete an existing collection item.

### Products
- **List Products**: List products for a selected site.
- **Get Product**: Retrieve a selected product.
- **Create Product**: Create a new product with default SKU data.
- **Update Product**: Update an existing product.
- **Update Product SKU**: Update a specific SKU of a product.

### Inventory
- **Get Item Inventory**: Retrieve the current inventory levels for a SKU item.
- **Update Item Inventory**: Update the current inventory levels for a SKU item.

### Assets
- **List Assets**: List assets for a selected site.
- **Get Asset**: Retrieve metadata for a selected asset.
- **Delete Asset**: Delete a selected asset.
- **Create Asset Folder**: Create an asset folder in a site, optionally under a parent folder.
- **Get Asset Folder**: Retrieve details for a specific asset folder.
- **List Asset Folders**: List asset folders for a selected site.

### Forms
- **List Forms**: List forms for a selected site.
- **Get Form Schema**: Retrieve the schema for a selected form.
- **List Form Submissions**: List submissions for a selected form.
- **Get Form Submission**: Retrieve a selected form submission.
- **Update Form Submission**: Update hidden fields on a selected form submission.
- **Delete Form Submission**: Delete a selected form submission.

### Pages
- **List Pages**: List pages for a selected site.
- **Get Page**: Retrieve metadata for a selected page.

### Comments
- **List Comment Threads**: List comment threads.
- **Get Comment Thread**: Retrieve a specific comment thread.
- **List Comment Thread Replies**: List the replies for a specific comment thread.

### Custom Operations
- **Custom API Request**: Make a custom authenticated request to a Webflow API endpoint.

## Conclusion

Webflow helps you automate website, CMS, and ecommerce workflows inside Boltic. Use the Webflow node to manage sites, collections, items, products, inventory, assets, forms, pages, comments, and custom API requests in your workflows.
