# Webflow

Webflow is a website experience platform for designing, building, and managing websites, forms, ecommerce products, orders, and hosted assets. The Webflow node in Boltic lets you connect your Webflow account and automate common site and ecommerce workflows.

## Webflow Account

- Select the Webflow account you want to connect.
- If you don't have an existing account, add one using the **Add New Account** option before proceeding.
- Your Webflow credentials are encrypted and can be removed at any time.

## Available Resources

Here are the available resources you can use with the **Webflow** node:

### Resources
- **Sites**: Manage Webflow sites by listing sites, retrieving site details, listing custom domains, and publishing sites.
- **Forms**: Work with forms by listing forms, retrieving form schemas, listing submissions, retrieving submissions, and deleting submissions.
- **Products**: Manage ecommerce products by listing products and retrieving product details.
- **Orders**: Manage ecommerce orders by listing orders, retrieving order details, updating order metadata, and fulfilling orders.
- **Assets**: Manage hosted assets by listing assets, retrieving asset metadata, and deleting assets.
- **Custom API**: Execute custom authenticated Webflow API calls with full flexibility.

## Basic Operations

Here are the basic operations you can perform with the Webflow node:

### Sites
- **List Sites**: List all accessible Webflow sites.
- **Get Site**: Retrieve details for a specific site.
- **Get Custom Domains**: List custom domains configured for a site.
- **Publish Site**: Publish a site to selected custom domains and optionally to the Webflow subdomain.

### Forms
- **List Forms**: List forms for a selected site.
- **Get Form Schema**: Retrieve the schema for a selected form.
- **List Form Submissions**: List submissions for a selected form.
- **Get Form Submission**: Retrieve a selected form submission.
- **Delete Form Submission**: Delete a selected form submission.

### Products
- **List Products**: List products for a selected site.
- **Get Product**: Retrieve a selected product.

### Orders
- **List Orders**: List orders for a selected site.
- **Get Order**: Retrieve a selected order.
- **Update Order**: Update order metadata such as internal notes, shipping provider, tracking number, and tracking URL.
- **Fulfill Order**: Mark a selected order as fulfilled and optionally send the fulfilled email to the customer.

### Assets
- **List Assets**: List assets for a selected site.
- **Get Asset**: Retrieve metadata for a selected asset.
- **Delete Asset**: Delete a selected asset.

### Custom Operations
- **Custom API Request**: Make a custom authenticated request to a Webflow API endpoint.

## Conclusion

Webflow helps you automate website and ecommerce workflows inside Boltic. Use the Webflow node to manage sites, forms, products, orders, assets, and custom API requests in your workflows.
