# Webflow Trigger
Webflow is a visual website builder and CMS for creating and managing websites, forms, and content. This integration connects Webflow with Boltic so you can trigger workflows when form submission webhook events occur.

## Webflow Account
- Select the Webflow account you want to connect.
- If you do not have an existing account, add one using the **Add New Account** option before proceeding.

## Available Resource
Here is the available resource you can use with the **Webflow** node:

### Resource
- **Webhook**: A webhook is a real-time HTTP callback that sends event data to your URL when actions occur in Webflow.

## Basic Operations
Here are the basic operations you can perform with the Webflow webhook trigger:

### Webhook Events
- **Form Submission**: Triggered when the selected Webflow form receives a new submission.

### Trigger Configuration
- **Webflow Site**: Select the site that you would like to receive notifications from.
- **Form Name**: Select the form you want to monitor. Forms appear only after they have been published and received at least one submission.

## Conclusion
Webflow webhooks let you build real-time automations around form submissions. Once configured, your workflow will receive event payloads whenever the selected form is submitted in Webflow.
