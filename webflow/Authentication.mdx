# Webflow Authentication

## Overview

The Webflow integration lets Boltic workflows manage sites, forms, ecommerce products and SKUs, orders, assets.
Webflow APIs in Boltic use Personal Access Token authentication for connecting your Webflow account.

## Authentication

Authenticate Webflow using a Personal Access Token.

Steps:

1. Sign in to Webflow - 
Log in to your Webflow account.

2. Generate a Personal Access Token - 
Create a Personal Access Token from your Webflow account settings. Refer to Webflow's authentication documentation for detailed instructions.

3. Open Boltic - 
Go to the Webflow source configuration page in Boltic.

4. Select Authentication Type - 
Choose `Access Token` from the **Authentication Type** dropdown.

5. Enter Personal Access Token - 
Paste your token into the **Personal Access Token** field.

6. Save and Continue - 
Save the configuration and proceed with the setup in Boltic.
