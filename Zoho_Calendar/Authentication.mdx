## Zoho Calendar

### Overview
The ZohoCalendar node allows you to connect your application with Zoho Calendar to automate tasks such as event scheduling, calendar management, meeting coordination, and resource booking. It helps streamline your scheduling workflows by enabling seamless integration with your calendar data and team collaboration features.

### Authentication Ways
- OAuth 2.0 <a href="https://www.zoho.com/calendar/help/api/oauth2-user-guide.html" target="_blank">Zoho Documentation</a>

### OAuth 2.0
To use the ZohoCalendar node, you need to authenticate using OAuth 2.0. Follow the steps below to set up your OAuth credentials and authorize access to your Zoho Calendar data.

**Steps:**
1. **Connect via Boltic**
   - In Boltic's integration configuration, select ZohoCalendar and enter a Name for your connection.

2. **Authorize Access**
   - Click Connect or Authorize.
   - You will be redirected to the Zoho Accounts login and consent screen.
   - Sign in with your Zoho credentials and grant the requested scopes (e.g. `ZohoCalendar.calendar.ALL`, `ZohoCalendar.event.ALL`, `ZohoCalendar.search.READ`).
   - Once the Connect button indicator turns green, return to Boltic and click Save — your OAuth tokens are now securely stored.

3. **Token Handling**
   - After successful authorization, Boltic securely stores both the access token and refresh token.
   - Access tokens are valid for 1 hour; when they expire, Boltic will automatically use the refresh token to obtain a new access token behind the scenes.

For detailed API usage (endpoints, request/response formats, supported modules and operations), see the <a href="https://www.zoho.com/calendar/help/api/introduction.html" target="_blank">Zoho Calendar API reference</a>
