# Salla Integration

Salla is an e-commerce platform for building and running online stores (products, orders, customers, shipping, payments, and store management). The Salla node in Boltic lets you connect your Salla account and automate store operations using common Salla resources and operations.

## Salla Account

- Select the Salla account you want to connect.
- If you don't have an existing account, add one using the **Add New Account** option before proceeding.

## Available Resources

Here are the available resources you can use with the **Salla** node:

### Resources
- **Products**: Manage products in your store - create products, list product details, update product status, and bulk update prices.
- **Product Tags**: Organize products using tags - create and list product tags.
- **Product Quantity**: Track and update inventory - list product quantities, bulk update stock, and list quantity change reasons.
- **Categories**: Manage product categories - create categories, list categories, view category details, list products in a category, and list child categories.
- **Customers**: Manage customers - create customers, list customers, view customer details.
- **Orders**: Manage orders - List orders and view order details, list order statuses and history, view order items, and delete order items.
- **Invoices**: Manage invoices - create invoices, list invoices, view invoice details, and send invoices to customers.
- **Custom API**: Execute custom API calls with full flexibility.

## Basic Operations

Here are the basic operations you can perform with the Salla node:

### Products
- **Create Product**: Create a new product.
- **List Products**: List products in the store.
- **Get Product Details**: Retrieve product details.
- **Delete Product**: Delete a product.
- **Change Product Status**: Change a product's status.
- **Update Bulk Product Prices**: Bulk update product prices.

### Product Tags
- **List Product Tags**: List product tags in the store.
- **Create Product Tag**: Create a new product tag.

### Product Quantity
- **List Product Quantities**: List product quantities.
- **Update Bulk Quantities**: Bulk update product quantities by ID or SKU.
- **List Quantity Change Reasons**: List reasons for inventory quantity changes.

### Categories
- **Create Category**: Create a new category.
- **List Categories**: List categories in the store.
- **Get Category Details**: Retrieve details for a category.
- **List Category Products**: List products in a category with their sort order.
- **Delete Category**: Delete a category.
- **List Child Categories of Category**: List child categories of a category.

### Customers
- **Create Customer**: Create a new customer.
- **List Customers**: List customers in the store.
- **Get Customer Details**: Retrieve customer details.

### Orders
- **List Orders**: List orders in the store.
- **Get Order Details**: Retrieve order details.
- **List Order Statuses**: List order statuses and sub-statuses.
- **Get Order Status Details by Status ID**: Retrieve order status details.
- **List Order Histories**: List order history for an order.
- **Get Order Items by Order ID**: List order items for an order.
- **Delete Order Item by Item ID**: Delete an order item.

### Invoices
- **List Order Invoices**: List invoices for orders.
- **Get Invoice Details**: Retrieve details for an invoice.
- **Send Order Invoice to Customer**: Email the order invoice to the customer.
- **Create Order Invoice**: Create an invoice for an order.

### Custom Operations
- **Custom API**: Execute custom API calls with full flexibility.

## Conclusion

Salla helps you automate store workflows inside Boltic. Use the Salla node to manage products, categories, customers, orders, invoices, and inventory quantities in your workflows.
