# Fathom Integration
Fathom is a meeting intelligence platform that records calls, generates summaries, and provides searchable transcripts. The Fathom node in Boltic lets you connect your Fathom account and automate workflows using common Fathom resources and operations.

## Fathom Account
- Select the Fathom account you want to connect.
- If you do not have an existing account, add one using the **Add New Account** option before proceeding.

## Available Resources
Here are the available resources you can use with the **Fathom** node:

### Resources
- **Meetings**: List meetings and get meeting details.
- **Meeting Insights**: Get meeting summaries and transcripts.
- **Teams**: List teams and team members.
- **Custom API**: Call any Fathom endpoint with custom settings.

## Basic Operations
Here are the basic operations you can perform with the Fathom node:

### Meetings
- **List Meetings**: List meetings.

### Recordings
- **Get Summary**: Retrieve the summary for a meeting recording.
- **Get Transcript**: Retrieve the transcript for a meeting recording.

### Teams
- **List Teams**: List teams in the workspace.
- **List Team Members**: List team members in the workspace.

### Custom Operations
- **Custom API**: Call any Fathom endpoint with custom settings.

## Conclusion
Fathom helps you automate meeting workflows inside Boltic. Use the Fathom node to list meetings, access summaries and transcripts, and manage team data in your workflows.
