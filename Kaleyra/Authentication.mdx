# Kaleyra Authentication

## Overview

Kaleyra is a cloud communication platform that helps businesses connect with customers through voice, messaging, WhatsApp, SMS, email, and other communication channels.. In Boltic, the Kaleyra integration connects to your Kaleyra service account so you can use supported Voice operations such as click-to-call, call status lookup, call details, blacklist management, follow-ups, progressive dialer uploads, and OBD calls.

## Authentication Ways

- API Key

## API Key

Use API Key authentication to connect your Kaleyra account to Boltic.

The Kaleyra integration requires your Kaleyra **API Key**. This key is stored as an encrypted service account credential and is used when making requests to Kaleyra APIs.

**Steps:**

**Step 1: Get Your API Key**
- Sign in to your Kaleyra account.
- Copy the API key from your Kaleyra account or developer settings.

**Step 2: Add a Kaleyra Service Account**
- In Boltic, select **Add New Account** from the Kaleyra service account field.
- Choose **API Key** as the authentication type.
- Paste your Kaleyra API key into the **API Key** field.

**Step 3: Validate and Save**
- Boltic validates the API key using Kaleyra's account credits endpoint.
- After validation succeeds, save the service account.
- Your Kaleyra account is now connected and ready to use.
