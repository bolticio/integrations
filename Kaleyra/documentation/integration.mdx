# Kaleyra

Kaleyra is a cloud communication platform that helps businesses connect with customers through voice, messaging, WhatsApp, SMS, email, and other communication channels. The Kaleyra node in Boltic lets you connect your Kaleyra account and automate Voice workflows such as click-to-call, call status lookup, call details, blacklisting, follow-ups, progressive dialer uploads, and outbound dialer calls.

## Kaleyra Account

- Select the Kaleyra account you want to connect.
- If you don't have an existing kaleyra account, add one using the **Add New Account** option before proceeding.
- Your Kaleyra account credentials are encrypted and can be removed at any time.

## Available Resources

Here are the available resources you can use with the **Kaleyra** node:

### Resources

- **Voice**: Use Kaleyra Voice click-to-call, call status, call details, blacklist, follow-up, health, progressive dialer, and OBD call APIs.

## Basic Operations

Here are the basic operations you can perform with the Kaleyra node:

### Voice

- **Click-to-Call**: Connect two users through a Kaleyra bridge call.
- **Click-to-Call Status**: Fetch click-to-call records by call ID, date range, number, or page.
- **Get Call Details**: Fetch incoming forwarded call details.
- **Blacklist a Number**: Blacklist one or more phone numbers for Voice calls.
- **Undo Number Blacklist**: Remove one or more phone numbers from the Voice blacklist.
- **Create Call Follow Up**: Create a scheduled call follow-up.
- **Edit Call Follow Up**: Edit or delete an existing scheduled call follow-up.
- **Get Call Follow Up Report**: Fetch call follow-up reports.
- **Health Status**: Check Kaleyra Voice API health status.
- **Progressive Dialer Upload**: Upload a single progressive dialer contact.
- **Progressive Dialer Bulk Upload**: Upload multiple progressive dialer contacts using JSON.
- **Start OBD Call**: Start outbound dialer calls using form parameters.
- **Start OBD Call Using JSON**: Start outbound dialer calls using a JSON payload.
- **Check OBD Call Status**: Check the status of an outbound dialer call.
- **Check OBD Group Status**: Check status for an outbound dialer group.

## Conclusion

Kaleyra helps you automate Voice communication workflows inside Boltic. Use the Kaleyra node to initiate calls, monitor call status, manage call follow-ups, handle blacklisted numbers, and run outbound dialer workflows.
