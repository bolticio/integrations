# Microsoft OneDrive

Microsoft OneDrive is a cloud storage platform that helps users store, organize, share, and collaborate on files and folders from anywhere. The Microsoft OneDrive node in Boltic lets you connect to your Microsoft OneDrive account to manage files and folders, sync data, and automate workflows through a set of operations designed for seamless file management.

## Microsoft OneDrive Account

- Select the Microsoft Onedrive account you want to connect.
- If you don't have an existing account, please add one using the "Add New Account" option before proceeding.

## Available Resources

Here are some of the available resources you can use with the **Microsoft OneDrive** node:

### Resources

- **File**: Create and find files in Microsoft OneDrive using their name or unique ID.
- **Folder**: Create and find folders in Microsoft OneDrive using their name or unique ID.
- **Custom**: Send requests to any Microsoft OneDrive endpoint using a provided URL and HTTP method.

## Basic Operations

Here are some of the basic operations you can perform with the Microsoft OneDrive node:

### File
- **Create File**: Create a new file in Microsoft OneDrive.
- **Find File by Name**: Search for a file using its name.
- **Find File by ID**: Get a specific file using its unique ID.

### Folder
- **Create Folder**: Create a new folder in Microsoft OneDrive.
- **Find Folder by Name**: Search for a Folder using its name.
- **Find Folder by ID**: Get a specific folder using its unique ID.
 
 ### Custom
 - **Custom API**: Send Microsoft OneDrive requests using a URL and method.

 ## Conclusion

Microsoft OneDrive is a secure and reliable cloud storage solution that makes it easy to store, access, manage, and automate files and folders across devices and applications.
