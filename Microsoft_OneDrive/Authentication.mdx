# Microsoft OneDrive

## Overview

Microsoft OneDrive is a cloud storage service that allows users to store, manage, and share files and folders online. This integration uses Microsoft Graph to access and manage OneDrive content programmatically.
## Authentication Ways

- Microsoft OAuth (OAuth 2.0)

## Microsoft OAuth (OAuth 2.0)
Users only need to sign in and grant permission to access their OneDrive.

**Steps:**
1. **Click Connect Microsoft OneDrive Account**

2. **Sign in with your Microsoft Email and Password**

3. **Review and allow the requested permissions**

    - Read files

    - Write / upload files

    - Manage folders

4. **After successful authorization, your Microsoft OneDrive account will be connected**
