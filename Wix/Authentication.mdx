# Wix Authentication

## Overview

Wix is a website, ecommerce, CMS, CRM, and content platform for building and managing online businesses.
Wix APIs in Boltic use API Key authentication combined with your Site ID to connect to your Wix site.

## Authentication

Authenticate Wix using an API Key and Site ID.

Steps:

1. Sign in to Wix -
Log in to your Wix account at wix.com.

2. Generate an API Key -
Go to the Wix Developers Center (manage.wix.com/account/api-keys) and create a new API key. Grant the key permissions for the resources you plan to use (Contacts, Stores, Forms, etc.).

3. Find your Site ID -
Open your Wix dashboard for the site you want to connect. The Site ID is visible in the dashboard URL: `manage.wix.com/dashboard/<site-id>/home`. Alternatively, go to Settings > General Info to find it.

4. Open Boltic -
Go to the Wix source configuration page in Boltic.

5. Authentication Type -
The authentication type is set to `API Key` automatically.

6. Enter API Key -
Paste your Wix API key into the **API Key** field.

7. Enter Site ID -
Paste your Wix Site ID into the **Site ID** field.

8. Save and Continue -
Save the configuration and proceed with the setup in Boltic.
