# Wix Trigger

Wix is a website, ecommerce, CMS, CRM, and content platform for building and managing online businesses. This trigger connects Wix with Boltic so you can start workflows when new or updated Wix records are found, including orders, products, categories, contacts, CMS collections, CMS items, blog posts, form submissions, and inbox messages.

## Wix Account

- Select the Wix account you want to connect.
- If you do not have an existing account, add one using the **Add New Account** option before proceeding.
- Your Wix account must include the site and app permissions required by the trigger you select.

## Available Resource

Here is the available resource you can use with the **Wix** trigger:

### Resource

- **Webhook**: Receives new or updated records from your connected Wix site.

## Basic Operations

Here are the basic operations you can perform with the Wix webhook trigger:

### Webhook Events

- **New or Updated Order**: Triggered when an order is created or updated in your Wix store.
- **New or Updated Product**: Triggered when a product is created or updated in your Wix store.
- **New or Updated Category**: Triggered when a category is created or updated in your Wix store.
- **New Contact**: Triggered when a new contact is created in Wix CRM.
- **New CMS Collection**: Triggered when a new CMS collection is created.
- **New CMS Item**: Triggered when a new item is added to the selected Wix CMS collection.
- **New Draft Blog Post**: Triggered when a new draft blog post is created.
- **New Published Blog Post**: Triggered when a new blog post is published.
- **New Form Submission**: Triggered when the selected Wix form receives a new submission.

### Trigger Configuration

- **Wix Account**: Select the Wix account and site credentials to use.
- **Resource**: Select **Webhook**.
- **Operation**: Select the Wix event you want to monitor.

## Conclusion

Wix triggers let you build automations around ecommerce, CMS, CRM, blog, forms, and inbox activity. Once configured, your workflow will receive event payloads whenever the selected Wix polling trigger finds new matching records.
