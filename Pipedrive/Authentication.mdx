# Pipedrive

## Overview
Pipedrive provides a sales CRM platform for managing leads, deals, contacts, and activities. With Boltic, users can integrate Pipedrive with Boltic to sync data, monitor sales performance, and automate workflows securely.  
Access to Pipedrive's API is authenticated using a **Personal API Key** to ensure secure and authorized communication.

## Authentication Ways

- API Key (Personal API Key)

## API Key (Personal API Key)

To authenticate with Pipedrive, you need your Pipedrive personal API key generated from your Pipedrive account.

**Steps:**

1. **Sign In to Pipedrive**  
   - Open your Pipedrive account and log in.

2. **Generate or Retrieve a Personal API Key**  
   - In Pipedrive, go to **Personal preferences → API** to view or generate your **Personal API Key**.  
   - Copy the key and store it securely.

3. **Set Up the Pipedrive Integration in Boltic**  
   - Log in to your Boltic dashboard.  
   - Navigate to **Sources → + Add New Source → Search for "Pipedrive"**.  
   - Fill in the required details:  
     - **Name:** Enter a name for your Pipedrive integration. 
     - **Personal API Key:** Paste your generated key.  
   - Click **Test Connection** to verify authentication, then select **Set up source** once successful.
