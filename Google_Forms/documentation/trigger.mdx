# Google Forms Trigger

Google Forms is a form builder for creating surveys, quizzes, registrations, and data collection workflows. This trigger connects Google Forms with Boltic so you can start workflows when new form responses are found in a connected Google Forms account.

## Google Forms Account

- Select the Google Forms account you want to connect.
- If you do not have an existing account, add one using the **Add New Account** option before proceeding.
- Your Google Forms account must have permission to read the selected form and its responses.
- Your credentials are encrypted and can be removed at any time.

## Available Resource

Here is the available resource you can use with the **Google Forms** trigger:

### Resource

- **Webhook**: Monitors Google Forms for new responses from the selected form.

## Basic Operations

Here are the basic operations you can perform with the Google Forms webhook trigger:

### Webhook Events

- **New Form Response**: Triggered when a new response is submitted to the selected Google Form.

### Trigger Configuration

- **Google Forms Account**: Select the Google Forms account credentials to use.
- **Resource**: Select **Webhook**.
- **Operation**: Select **New Form Response**.
- **Form**: Select the Google Form whose responses you want to monitor.


## Conclusion

Google Forms triggers let you build automations around new form submissions. Once configured, your workflow will receive event payloads whenever the selected polling trigger finds new matching form responses.
