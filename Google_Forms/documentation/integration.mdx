# Google Forms

Google Forms is a form builder for creating surveys, quizzes, registrations, and data collection workflows. The Google Forms node in Boltic lets you connect your Google account and automate common workflows for forms, form responses, Google Sheets response data, and custom authenticated Google API requests.

## Google Forms Account

- Select the Google Forms account you want to connect.
- If you don't have an existing account, add one using the **Add New Account** option before proceeding.
- Your Google Forms credentials are encrypted and can be removed at any time.

## Available Resources

Here are the available resources you can use with the **Google Forms** node:

### Resources

- **Form**: Search, create, retrieve, update, or move Google Forms to trash.
- **Response**: List form responses or retrieve a specific response from a form.
- **Response in Google Sheets**: Search, query, add, update, or delete form responses stored in a linked Google Sheet.
- **Custom**: Make a custom authenticated request to Google Forms, Google Drive, Google Sheets, or another supported Google API endpoint.

## Basic Operations

Here are the basic operations you can perform with the Google Forms node:

### Form

- **Search Forms**: Retrieve a list of Google Forms filtered by criteria.
- **Create a Form**: Create a new Google Form.
- **Get a Form**: Retrieve an existing form by its ID.
- **Update a Form**: Update an existing form by its ID, including title, description, and form items.
- **Move a Form to Trash**: Move a form to trash.

### Response

- **List Responses**: Retrieve a list of responses submitted to a selected form.
- **Get a Response**: Retrieve the details of a specific response by response ID.

### Response in Google Sheets

- **Search Responses in Google Sheets**: Retrieve rows from a selected spreadsheet and sheet, with optional filtering by header name and value.
- **Search Responses in Google Sheets (Advanced)**: Query response rows using the Google Charts Query Language.
- **Add a Response in Google Sheets**: Append a new response row to the bottom of a selected sheet.
- **Update a Response in Google Sheets**: Update response cells or rows in a selected spreadsheet range.
- **Delete a Response in Google Sheets**: Clear a response row or range from a selected spreadsheet.

### Custom Operations

- **Make an API Call**: Perform an arbitrary authenticated API call to a Google Forms, Drive, Sheets, or related Google API endpoint.


## Conclusion

Google Forms helps you automate form creation, response collection, spreadsheet response management, and custom Google API workflows inside Boltic. Use the Google Forms node to manage forms, read responses, work with linked Google Sheets data, and make custom authenticated Google API requests in your workflows.
