## AIPIM Authentication

### Prerequisites

-   Create an AIPIM account and have administrative access to your organization.

### Supported Authentication Methods

-   API Key

### Using API Key

To configure this secret, you'll need:

1. **API Key**: Generate an API key in your AIPIM dashboard under **Settings** > **API Keys**. Ensure the key has permissions for webhook management (read, write, delete webhooks).

Refer to the [AIPIM API Key documentation](https://docs.aipim.com/api-keys) for detailed instructions on generating your API key.
