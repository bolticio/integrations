# Discord

Discord is a communication platform for gaming, communities, and teamwork, supporting voice, video, and text conversations. This integration connects Discord with Boltic so you can trigger workflows from key events in your server.

## Discord Account

- Select the Discord account you want to connect.
- If you do not have an existing account, add one using the **Add New Account** option before proceeding.

## Available Resource

Here are the available resources you can use with the **Discord** node:

### Resource
- **Webhook**: A webhook is a real-time HTTP callback that sends event data to your URL when actions occur in Discord.

## Basic Operations

Here are the basic operations you can perform with the Discord node:

### Webhook Events
- **New User Added**: Triggers when a new user joins the Discord server.
- **New Message Posted on Channel**: Triggers when a new message is posted to a specific text channel.
- **New Forum Message**: Triggers when a new message is created on a forum post.
- **New Forum Post**: Triggers when a new post is created in a forum.
- **New Mention**: Triggers when a user or role is mentioned.

## Conclusion
Discord webhooks let you build real-time automations by subscribing to server, channel, forum, and mention events. Once configured, your workflow will receive event payloads whenever these changes occur in Discord.
