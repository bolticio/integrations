# Microsoft To Do

Microsoft To Do is a simple task management app that helps you create to-do lists, set reminders, and organize tasks across devices.

## Microsoft To Do Account

- Select the Microsoft To Do account you want to connect.
- If you don't have an existing account, please add one using the "Add New Account" option before proceeding.

## Available Resources

Here are some of the available resources you can use with the **Microsoft To Do** node:

### Resource

- **Webhook**: A webhook is a real-time HTTP callback that posts event data to your URL when specified actions happen in Microsoft To Do, so your system can react instantly.

## Basic Operations

Here are some of the basic operations you can perform with the Microsoft To Do node:

### Task
- **Task Completion**: Triggers when a task is completed in Microsoft To Do list.
- **Task Created**: Triggers when a new task is created in Microsoft To Do list.
- **Task Updated**: Triggers when a task is updated in Microsoft To Do list.
 
 ## Conclusion

Microsoft To Do is a simple and efficient task management solution that helps you create, organize, track, and automate tasks and lists across devices, keeping your work and daily life well organized.
