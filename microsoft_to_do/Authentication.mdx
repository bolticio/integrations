# Microsoft To Do

## Overview

Microsoft To Do is a simple task management app that helps you create to-do lists, set reminders, and organize tasks across devices.
## Authentication Ways

- Microsoft OAuth (OAuth 2.0)

## Microsoft OAuth (OAuth 2.0)
Users only need to sign in and grant permission to access their To Do.

**Steps:**
1. **Click Connect Microsoft To Do Account**

2. **Sign in with your Microsoft Email and Password**

3. **Review and allow the requested permissions**

    - Get Lists

    - Create / Update lists and tasks

    - Manage tasks

4. **After successful authorization, your Microsoft To Do account will be connected**
