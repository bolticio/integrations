# Google Contacts

The Google Contacts node enables your applications to interact with Google Contacts, allowing you to manage and organize contact information efficiently. This guide will help you authenticate and perform various operations within your Google account.

## Google Contacts Account

- Select the Google account you want to connect.
- If you don't have an existing account, please add one using the **Add New Account** option before proceeding.

## Available Resources

Here are some of the available resources you can use with the **Google Contacts** node:

### Resources

- **Contact**: Lets users store and organize contact information.
- **Group**: Organize contacts into groups/labels for better categorization.
- **Custom**: Send requests to any Microsoft Outlook endpoint using a provided URL and HTTP method.

## Basic Operations

Here are some of the basic operations you can perform with the Google Contacts node:

### Contacts

- **Create Contact**: Add a new contact to your Google Contacts.
- **Delete Contact**: Delete an existing contact.
- **Update Contact**: Edit existing contact details.
- **Find Contact**: Search for a contact in Google Contacts.

### Group

- **Create Group**: Create a new label/group for organizing contacts.
- **Delete Group**: Remove a group permanently from your account.
- **Add Contact to Group**: Assign one or more contacts to a specific group.

### Custom
 - **Custom API**: Send Google Contacts requests using a URL and method.

## Conclusion

The Google Contacts node provides a simple and efficient way to manage your contacts and organize them into groups. By setting up authentication and using the available operations, you can automate contact management workflows directly within your applications.
