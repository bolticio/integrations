# Granola Authentication

## Overview

Granola is an AI-powered meeting notes platform that helps teams capture, organize, and access meeting notes and transcripts. Granola APIs are authenticated using an API Key to ensure secure and authorized communication.

## Authentication Ways

### API Key

To authenticate with Granola, generate an API Key from your Granola workspace settings and configure it in Boltic.

Steps:

1. Sign in to Granola

Go to your Granola workspace and log in.

2. Open Workspace Settings

Navigate to your workspace settings in Granola.

3. Open API Settings

Go to the API section for your workspace.

4. Generate API Key

Create a new API key for your workspace.

5. Configure in Boltic

Enter the generated Granola API Key when configuring the Granola account in Boltic.
