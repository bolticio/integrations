# Granola

Granola is an AI-powered meeting notes platform that helps teams capture, organize, and access meeting notes and transcripts. The Granola node in Boltic lets you connect to your Granola account and automate workflows using Granola notes resources and operations.

## Granola Account

- Select the Granola account you want to connect.
- If you don't have an existing account, add one using the **Add New Account** option before proceeding.

## Available Resources

Here are the available resources you can use with the **Granola** node:

### Resources

- **Notes**: List meeting notes and retrieve a specific note by ID.
- **Custom**: Make a custom Granola API request with your own URL, method, query string, and payload.

## Basic Operations

Here are the basic operations you can perform with the Granola node:

### Notes

- **List Notes**: List accessible meeting notes with optional filters such as created before, created after, and updated after.
- **Get Note by ID**: Retrieve a meeting note using the note ID.

### Custom

- **Custom API Request**: Make a custom request to a Granola API endpoint using a user-provided URL, HTTP method, optional query string parameters, and optional request body.

## Conclusion

Granola makes it easy to build meeting documentation workflows and automate note retrieval, letting you list meeting notes, fetch note details, and make custom Granola API requests within Boltic.
