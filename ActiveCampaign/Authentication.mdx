# ActiveCampaign Authentication

## Overview

ActiveCampaign is a customer experience automation platform that helps businesses manage contacts, email marketing campaigns, sales pipelines, and customer interactions.

## Authentication Ways

- API URL
- API Key

## How to Find Your ActiveCampaign API Credentials

**Step 1: Log in to ActiveCampaign**
- Sign in to your ActiveCampaign account.

**Step 2: Open Settings**
- Click **Settings** from the left navigation menu.

**Step 3: Go to Developer Settings**
- In the Settings menu, select **Developer**.

**Step 4: Copy Your API URL**
- Under the **API Access** section, locate the **API URL**.
- Copy and save this value.

**Step 5: Copy Your API Key**
- In the same **API Access** section, locate the **API Key**.
- Copy and save this value securely.

## Connect ActiveCampaign to Boltic

**Step 1: Open ActiveCampaign Connection**
- In Boltic, navigate to the ActiveCampaign integration and click **Connect Account**.

**Step 2: Enter Credentials**
- Paste your **API URL** into the API URL field.
- Paste your **API Key** into the API Key field.

**Step 3: Save Connection**
- Click **Test and Save**.

**Step 4: Verify Connection**
- Once validated, your ActiveCampaign account will be connected and ready to use within Boltic.

## Important Notes

- Keep your API Key confidential and do not share it publicly.
- If your API Key is regenerated in ActiveCampaign, you will need to update it in Boltic.
- Ensure the API URL is copied exactly as displayed in ActiveCampaign.
