# Zendesk Gather

Zendesk Gather is a community platform that lets you manage badge categories, badges, and badge assignments. The Zendesk Gather node in Boltic connects securely to your workspace so you can automate badge workflows, synchronize data, and power community analytics.

## Zendesk Account

- Select The Zendesk Account You Want To Connect. 
- If You Don't Have An Existing Account, Please Add One Using The " Add New Account" Option Before proceeding.

## Available Resources

Here are the available resources exposed by the **Zendesk Gather** node:

### Resources
- **Badge Categories**: Define and organize badge groupings tied to specific brands.
- **Badges**: Manage individual community badges, their metadata, and category placements.
- **Badge Assignments**: Link badges to users and audit who has earned which achievements.

## Basic Operations

The Zendesk Gather node ships with dedicated operations for each resource.

### Badge Categories
- **Create Badge Category**: Create a new badge grouping category.
- **List Badge Categories**: Retrieve all existing badge categories.
- **Get Badge Category by ID**: Fetch the details of a specific category.
- **Delete Badge Category**: Remove a category permanently.

> **Brand ID:** `Admin Center → Account → Brand Management → Brand`; copy the ID from the URL segment after `/brand`.  


### Badges
- **Create Badge**: Create a new badge within a category.
- **List Badges**: Retrieve all badges in the workspace.
- **Get Badge by ID**: View details of a specific badge.
- **Update Badge**: Modify badge properties (name, description, category, etc.).
- **Delete Badge**: Remove a badge permanently.


### Badge Assignments
- **Create Badge Assignment**: Assign a badge to a user.
- **List Badge Assignments**: Retrieve all badge-to-user mappings.
- **Delete Badge Assignment**: Remove a badge assignment from a user.

> **User ID:** `Admin Center → People → Team Members → Select user`; the URL segment after `/members` contains the ID.
