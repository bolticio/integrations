
# Zendesk Gather Authentication

## Overview

Zendesk Gather lets you automate badges, badge categories, assignments, and user roles for your community. This guide walks through the private authentication flow so only the account owner can connect the integration.

## Authentication Ways
- API Token

## API Token Authentication

Use an API token generated in the Zendesk Admin Center to authorize every request.

**Steps:**

1. **Log In to Zendesk**
    - Visit `https://{subdomain}.zendesk.com` and sign in as an admin or agent.

2. **Open Admin Center**
   - Open the Admin panel by clicking the gear icon in the sidebar.

3. **Open API Token Settings**
    - Go to **Apps and integrations** > **APIs** > **API tokens**.

4. **Enable API Token Access**
    - Confirm **Allow API token access** is selected.
    - When **API & Integrations** opens, check the box to expose the **Enable API Access** control, then grant the requested permissions.

5. **Create a Token**
    - Click **Add API token**, give it a name such as “Gather Integration,” save, and copy the token to a secure location.

6. **Collect Credentials**
    - Zendesk subdomain (for example, `yourcompany`)
    - Admin or agent email address (must allow API access)
    - API token (generated above)

7. **Test the Connection**
    - Provide the subdomain, email, and token to your integration settings to ensure authentication succeeds.
